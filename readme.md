# Bogdan's Photography Portfolio

Self-hosted photography portfolio: a public gallery with a contact form, and an
admin mode for publishing photos. Runs on a Raspberry Pi, with photos stored
on an external drive.

See [docs/design.md](docs/design.md) for the full architecture, data model,
and deployment plan.
